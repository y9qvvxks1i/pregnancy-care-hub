# 输卵管积水又称“神秘之水”    不治会影响试管成功率

> 更新时间：2026-09-16 (UTC+8)

最近有患者咨询：说自己做B超和输卵管造影发现了输卵管积水，要不要处理？不处理会对移植产生什么不好的影响？

其实做试管婴儿的患者有时会遇到输卵管积水，而且输卵管积水极易变化，有时B超可以测出，有时又“神秘的消失”，很多病人为输卵管积水反复而苦恼，今天我们就来揭开它的真面目吧！

什么原因导致的积水？

1. 输卵管积水多出现于不洁性生活、流产及产后感染等。

 

2. 急性盆腔输卵管炎治疗不彻底或不及时转变为慢性输卵管炎，此时输卵管伞端因炎症而粘连闭锁，输卵管管腔内的漏出液、渗出液逐渐积聚成输卵管积水。

 

3. 有的输卵管积水由输卵管积脓转变而成，原来管腔内的脓细胞及坏死组织被分解吸收，脓液逐渐转为清亮水样液。

 

4. 然而也有的输卵管积水并不是由输卵管炎症引起，而是继发于输卵管绝育术后。

 

输卵管积水如何被发现

输卵管积水的患者多数无明显症状，有时不孕是唯一症状，如部分管腔仍与宫腔相通，可出现白带增多甚至阴道大量排液的症状，同时输卵管积水受月经周期影响，雌激素高时，液体增多，再者这个疾病二维超声诊断敏感性并不高，但特异性高，换句话讲就是少量不严重的积水超声不一定能检出，但一旦发现，就说明比较严重了。此时输卵管积水就显得变化莫测，有时有，有时无，有时多，有时少。所以输卵管积水不是一成不变，需动态监测。

输卵管积水会影响助孕成功率

输卵管积水对IVF-ET存在许多不利影响，使得胚胎种植率低、临床妊娠率低、流产率高、异位妊娠率高。输卵管积水可逆流入宫腔，对胚胎有“冲刷作用”，同时可造成宫腔积水，干扰胚胎与子宫内膜的接触，同时输卵管积水有毒性作用，不利于胚胎发育成囊胚，最后输卵管积水时输卵管增粗，使胚胎容易游入输卵管，形成宫外孕，因此在IVF前对严重的输卵管积水进行处理具有重要意义。
